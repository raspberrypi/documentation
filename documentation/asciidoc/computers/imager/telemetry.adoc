[[telemetry]]
== Telemetry

By default, Imager collects anonymous usage statistics (telemetry). Raspberry Pi uses these statistics to understand which operating systems and versions of Imager people use, and to prioritise work on Imager.

When you write an image, Imager sends the following information:

* The URL, category, and name of the OS you selected
* The version of Imager
* Whether Imager is running on a desktop computer or as part of Network Install
* The version, architecture, and locale of your computer's operating system
* When running as part of Network Install, the revision of your Raspberry Pi

Raspberry Pi stores this data as aggregate counts, and doesn't associate any personal data with them. To see the aggregate data, visit https://rpi-imager-stats.raspberrypi.com[rpi-imager-stats.raspberrypi.com]. For more information about how the data is stored, see the https://github.com/raspberrypi/rpi-imager#anonymous-metrics-telemetry[Imager README].

[[telemetry-opt-out]]
=== Turn off telemetry

To turn off telemetry, do one of the following:

* Select *App Options*, turn off *Enable anonymous statistics (telemetry)*, and then select *Save*.
* Launch Imager with the `--disable-telemetry` option. Imager saves this setting for future launches.
