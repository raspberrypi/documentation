A single-board computer (SBC) is a complete, functional computer built on a printed circuit board (PCB). Classic Raspberry Pi SBCs integrate the following onto one board:

* A System on Chip (SoC).
* Memory.
* A GPIO header.
* Various connectivity options.

All components and ports are exposed, but you can buy a bumper or case to protect them. You can use a Raspberry Pi SBC safely without a bumper or case so long as you don't place it on a metal surface. If you place a Raspberry Pi SBC without a case on a metal surface, it can short-circuit.

You can also connect various peripherals, such as a screen, keyboard, and mouse. For instructions, see xref:../computers/getting-started.adoc#setup[Set up your Raspberry Pi].

NOTE: If you have a Raspberry Pi 400, 500, or 500+, the Raspberry Pi circuit board is built into the keyboard case. For more information about these devices, see xref:../computers/keyboard-computers.adoc[Keyboard computers].

== Models

Raspberry Pi devices have evolved through various models, improving on performance, connectivity, and functionality to serve different use cases.

=== Model variants

Model variants within a generation of classic SBC models are sometimes designated a letter, *A* or *B*, which indicates the form factor and feature set differences within that generation.

* *Model B* indicates a full-featured variant that includes an Ethernet port and multiple USB ports, suitable for general-purpose use.
* *Model A* indicates a lower-cost, smaller variant with no Ethernet port and fewer USB ports, suitable for more space-constrained applications.
