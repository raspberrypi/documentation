Raspberry Pi makes computers that can be split into five main hardware **series**:

* *Classic single-board computers (SBCs).* The classic Raspberry Pi SBC series offers high-performance hardware, a full Linux operating system, and a variety of common ports in a form factor roughly the size of a credit card. For more information, see xref:../computers/sbcs.adoc[Classic single-board computers (SBCs)].
* *Raspberry Pi Zero.* Small and affordable models in a minimal form factor that provide a full Linux operating system and essential ports with low power consumption. For more information, see xref:../computers/zero.adoc[Zero models].
* *Keyboard computers (X00).* SBC hardware, a full Linux operating system, and common ports combined into a compact keyboard case. For more information, see xref:../computers/keyboard-computers.adoc[Keyboard computers].
* *Compute Module (CM)* Boards designed for embedded and industrial applications that provide the same hardware as classic SBCs but in a smaller form factor with no on-board connectors. Instead, they connect to a separate baseboard that supplies the necessary ports and pins. For more information, see xref:../computers/compute-module.adoc[Compute Module hardware].
* *Raspberry Pi Pico.* Small and versatile microcontroller boards that don't run Linux. Instead of removable storage, programs are flashed directly onto on-board memory. Pico microcontrollers are ideal for real-time control and lightweight embedded projects. For more information, see xref:../microcontrollers/pico-series.adoc[Pico microcontroller boards].

Most classic Raspberry Pi models, Raspberry Pi Zero models, and keyboard computers share a number of features, including:

* *A microSD slot.* A slot for a microSD card, which serves as the primary storage device and typically contains an operating system (OS) and user data.
* *USB connectivity.* At least one USB port for connecting peripherals. Raspberry Pi Zero models use a single micro-USB data port; classic models and keyboard computers offer multiple USB ports.
* *Power input.* While the physical connector on boards has evolved from micro-USB to USB-C, all boards are powered by a stable 5 V DC input.
* *General-purpose input/output (GPIO) pins.* A standardised interface consisting of 40 pins that allow your Raspberry Pi to communicate with additional hardware (like LEDs, buttons, sensors, and so on). For more information, see xref:../computers/raspberry-pi.adoc#gpio[40-pin GPIO header].
