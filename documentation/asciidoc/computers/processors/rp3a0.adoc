== RP3A0

The Raspberry Pi RP3A0 is our first System-in-Package (SiP) consisting of a Broadcom BCM2710A1. BCM2710A1 is the silicon die packaged inside the Broadcom xref:processors.adoc#bcm2837[BCM2837] chip, which is used on the xref:../computers/sbcs.adoc#rpi3b[Raspberry Pi 3] — along with 512 MB of DRAM.

It is used by the xref:../computers/zero.adoc#zero2w[Raspberry Pi Zero 2 W].

image:images/RP3A0-crosssection.png[width="70%"]

The RP3A0 is a quad-core 64-bit Arm Cortex A53 CPU clocked at 1 GHz, although with a heatsink or other cooling solution in place, the chip can be potentially overclocked to 1.2 GHz.

For details on the Arm peripherals specification, which also applies to the BCM2837 and RP3A0, see the following BCM2836 documents.

* https://pip.raspberrypi.com/documents/RP-008250-DS[BCM2836 Arm-local peripherals]
* https://support.arm.com/documentation/ddi0500/latest/[Cortex-A53 MPCore Processor Technical Reference Manual]

[NOTE]
====
The original xref:../computers/zero.adoc#zero[Raspberry Pi Zero] uses Package-on-Package (PoP) DRAM, where the DRAM is soldered directly on top of the xref:processors.adoc#bcm2835[BCM2835] chip.
====
