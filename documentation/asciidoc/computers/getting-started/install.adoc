[[install]]
== Install an OS onto boot media

To use your Raspberry Pi, you must first install (flash) an *operating system (OS)* onto your storage device, making it a boot device. By default, Raspberry Pi devices check for an OS on any SD card inserted into the SD card slot. Some Raspberry Pi models allow you to boot an OS from other storage devices, such as USB drives, storage connected through a HAT, and network storage. The following instructions assume that you're using a microSD card.

We recommend installing an OS to your storage device using *Raspberry Pi Imager* on another computer. For instructions, see <<imager-install>>. If you don't have access to another computer for writing an OS image to the storage device, you might be able to install an operating system directly on your Raspberry Pi from the internet. For instructions, see <<network-install>>.

=== Exceptions
Raspberry Pi 500 and some Raspberry Pi desktop and personal computer kits come with a microSD card that's pre-installed with Raspberry Pi OS. Raspberry Pi 500+ also includes an SSD with Raspberry Pi OS pre-installed. In these cases, you don't have to follow the installation instructions on this page. However, we recommend that you update the pre-installed software. For instructions, see xref:../computers/os.adoc#update-software[Update your current Raspberry Pi software].

Updating the software doesn't move your Raspberry Pi to a new major version of Raspberry Pi OS. For example, if your Raspberry Pi 500+ came with Raspberry Pi OS Bookworm, updating it doesn't install Trixie. To move to a new major version, reinstall Raspberry Pi OS using Network Install. You don't need another computer to do this. For instructions, see xref:imager.adoc#network-install-new-version[Move to a new version of Raspberry Pi OS].

If you want to reconfigure your Raspberry Pi, you can do so from the menu at the top of the display attached to your Raspberry Pi. For example, you can set or change your wireless network from the Wi-Fi icon in the top-right corner. For instructions, see xref:../computers/configuration.adoc#connect-to-wireless[Connect to a wireless network] in the *Configuration* page.

=== Prerequisites
To install an OS on a storage device, you need:

* A blank storage device to be your boot media, typically a microSD card. For more information, see xref:../computers/getting-started.adoc#boot-media[Boot media].
* A computer you can use to write the OS image onto your storage device so that your Raspberry Pi can boot from it.
* A way to plug your storage device into that computer.

[[imager-install]]
=== Install using Imager

xref:imager.adoc[Raspberry Pi Imager] is a tool you use to download and write OS images for your Raspberry Pi on Windows, macOS, and Linux. During installation, you can also preconfigure credentials and remote access settings for your Raspberry Pi.

The following steps cover a typical installation. For a detailed set of illustrated instructions, see xref:imager.adoc[Raspberry Pi Imager].

. Install and launch Imager on your computer. For instructions, see xref:imager.adoc#install-imager[Install Imager].
. In the *Device* tab, select your Raspberry Pi model and then select *Next*.
. In the *OS* tab, choose an operating system and then select *Next*. The recommended OS for your Raspberry Pi model is at the top of the list.
. Connect your storage device to your computer. For example, plug a microSD card into your computer using an external or built-in SD card reader.
. In the *Storage* tab, select your storage device and then select *Next*.
+
WARNING: Take care to choose the correct storage device, because Imager erases all data on it. We strongly recommend that you keep *Exclude system drives* selected to prevent you from accidentally erasing your computer's system drive. If you select a system drive, Imager asks you to enter the drive's name before it writes to it.

. In the *Customisation* tab, set your hostname, localisation, username and password, Wi-Fi, and remote access, selecting *Next* after each subtab. For details of each setting, see xref:imager.adoc#os-customisation[Customise your operating system].
+
We strongly recommend that you customise your OS now. If you're setting up a headless Raspberry Pi, you must configure Wi-Fi (or use Ethernet) and either Raspberry Pi Connect or SSH, so that you can connect to it after it boots. If you select *Skip customisation*, the OS asks you for the same information after first boot. For Raspberry Pi OS, this happens in the xref:getting-started.adoc#first-configuration[configuration wizard].
. In the *Writing* tab, review your choices and then select *Write*.
. To confirm that you want to erase your storage device, select *I understand, erase and write*.
. Wait while Imager writes and then verifies the image. We recommend that you let verification finish.
. When the *Done* tab appears, select *Finish*.

You can now follow the instructions for either the xref:getting-started.adoc#desktop-setup[Standard (desktop) setup] or the xref:getting-started.adoc#headless-setup[Headless (remote) setup] to get your Raspberry Pi started according to your needs.

[[network-install]]
=== Install over the network

If you don't have another computer, you can install an OS directly on your Raspberry Pi using *Network Install*. Your Raspberry Pi downloads Raspberry Pi Imager over a wired internet connection and runs it, so you don't need an SD card reader. For instructions, see xref:imager.adoc#network-install[Install over the network] in *Raspberry Pi Imager*.

NOTE: If you have a Raspberry Pi 500+ that came with Raspberry Pi OS Bookworm, use Network Install to move to a newer version of Raspberry Pi OS, such as Trixie. For instructions, see xref:imager.adoc#network-install-new-version[Move to a new version of Raspberry Pi OS].
