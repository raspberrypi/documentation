== Camera Module 2
This 8-megapixel camera has a resolution of 3280 × 2464 pixels. It has adjustable focus and can record an exposure time of up to 11.76 seconds.

== Variants

Camera Module 2 is available in the following variants:

* https://www.raspberrypi.com/products/camera-module-v2/[**Standard**.] This version captures visible light only; infrared light is filtered out.
* https://www.raspberrypi.com/products/pi-noir-camera-v2/[**NoIR**.] This version doesn't have an infrared filter; it captures both visible light and infrared light.

== Sensor change

Camera Module 2s manufactured before November 2026 use the Sony IMX219 sensor. Camera modules manufactured from November 2026 use the Sony IMX355 sensor.

The IMX355 sensor offers the same 8-megapixel resolution as the IMX219, but benefits from improved tuning algorithms that provide better colour reproduction.

=== Identifying the sensor

`IMX355` is printed on the silkscreen of Camera Module 2s that have that sensor installed. You can also use the Terminal to determine which sensor your camera module uses:

. Open the Terminal.
. Run the following command:
+
[source,console]
----
rpicam-hello --list-cameras
----
+
The terminal returns a list of connected cameras, including the sensor type. For example:
+
[source,console]
----
Available cameras----------------0 : imx355 [3280x2464 10-bit RGGB]
----

=== Updating your Linux driver

If you experience any issues running a new Camera Module 2 with the IMX355 sensor, perform a full update from the Terminal:

. Open the Terminal.
. Run the following commands:
+
[source,console]
----
sudo apt update
sudo apt full-upgrade
sudo reboot
----
